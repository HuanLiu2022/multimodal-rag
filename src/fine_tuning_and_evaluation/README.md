# Fine-tuning & Evaluation

This folder contains the notebooks used for model fine-tuning and evaluation.

| Notebook | Description |
|---|---|
| `BLIP2-Flan-T5-XL_Multitask_MET.ipynb` | Fine-tuning BLIP2-Flan-T5-XL with LoRA on The Met dataset for metadata and description generation. |
| `BLIP2-Flan-T5-XL_Multitask_UZH.ipynb` | Fine-tuning BLIP2-Flan-T5-XL with LoRA on the UZH dataset for German-language metadata and description generation. |
| `GPT-4o_Classifier_MET.ipynb` | Fine-tuning GPT-4o for structured artifact metadata classification on The Met dataset. |
| `GPT-4o_Classifier_UZH.ipynb` | Fine-tuning GPT-4o for structured artifact metadata classification on the UZH dataset. |
| `GPT-4o_Describer_MET.ipynb` | Fine-tuning GPT-4o for multimodal artifact description generation on The Met dataset. |
| `GPT-4o_Describer_UZH.ipynb` | Fine-tuning GPT-4o for German-language multimodal artifact description generation on the UZH dataset. |
